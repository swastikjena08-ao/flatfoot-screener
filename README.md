# Foot X-ray AI models

The trained AI models for reading foot X-rays: flat foot, heel spur, bunion angles, fracture flag and an X-ray check that says what kind of X-ray it is. Everything is in [`ai_models/`](ai_models/), with each model's code, test scores and how to run it.

The app is being rebuilt from scratch. The earlier apps are still in this repo's git history.
